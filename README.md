# ストックノート2.0

日用品と食材の在庫、賞味期限、買い足しを、スマートフォンの片手操作で確認するWebアプリです。データはブラウザの LocalStorage にだけ保存します。

## 起動

```bash
npm install
npm run dev
```

http://localhost:3000 を開きます。

```bash
npm run lint
npm run build
```

## 画面

- 在庫一覧: カテゴリーバッジ、期限と残量の赤・黄・緑、数量の増減、買い足しへの追加
- 買い足しリスト: 買い足しに入れた品だけを表示
- アイテム追加: 名前、カテゴリー、数量、単位、賞味期限

スマートフォン幅では画面下のナビで切り替えます。
